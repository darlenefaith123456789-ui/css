# Credit Scoring DSS – Online Demo

Static demo of the Credit Scoring Decision Support System for GitHub Pages.

- Sign in with username **admin**, password **admin**.
- Scoring uses the real trained Random Forest model (`model.json`), run in the browser.
- Sign-in, account requests, user management and saved assessments are **simulated** in the
  browser and reset when the tab is closed. The full system (Flask + MySQL) is in the main repository.
